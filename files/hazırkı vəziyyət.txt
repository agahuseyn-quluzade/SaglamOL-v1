Hazırkı Vəziyyət
Layihə artıq tək Spring Boot app deyil, Gradle multi-module microservice monorepo formasındadır. Backend-only e-health insurance platforması kimi qurulur.
Əsas struktur:

  common-events
  common-security
  common-exception

infrastructure/
  api-gateway
  config-server
  discovery-server

  iam-service
  user-profile-service
  policy-service
  claim-service
  health-record-service
  ai-risk-service
  fraud-detection-service
  notification-service
  payment-service

Yarana Biləcək Əsas Problemlər
1.
Docker Build Resurs Problemi
docker compose up -d --build zamanı Docker Desktop paralel build zamanı EOF xətası verdi. Buna görə Dockerfile-lar dəyişdirildi: artıq image build etməzdən əvvəl host-da jar build etmək daha stabil yoldur.
Tövsiyə olunan flow:
.\gradlew.bat bootJar
docker compose up -d --build
2.
Cədvəllərin Görünməməsi
Cədvəllər yalnız servis start olanda Liquibase tərəfindən yaranır. Sadəcə Docker Postgres-i qaldırmaq cədvəl yaratmır.
3.
IntelliJ Database Cache
IntelliJ köhnə saglamol_admin@localhost connection adını göstərə bilər. Bu real database deyil, stale data source ola bilər.
4.
Security Hələ Production Səviyyəsində Deyil
JWT hazırda HMAC secret ilədir. Production üçün daha doğru model:
IAM private key ilə sign edir
Gateway public key ilə validate edir
Bu sonrakı hardening mərhələsində edilməlidir.
5.
Servis Security-ləri Hələ Tam Standartlaşmayıb
IAM-də security var, Gateway-də validation var. Amma digər servislərdə TrustedContextFilter, RBAC və method-level authorization hələ tam yazılmayıb.
6.
Biznes API-lər Hələ Skeleton-dur
User/Profile, Policy, Claim və digər servislərdə entity/schema var, amma controller/service/repository biznes funksiyaları hələ tam yazılmayıb.
7.
Kafka/Outbox Hələ Tam İşlək Deyil
Kafka container var, common event envelope var, amma outbox publisher və consumer-lər hələ implement edilməyib.
8.
Docker Service Healthcheck-lər App-lər Üçün Tam Deyil
Infra container-lərdə healthcheck var. App service-lər üçün /actuator/health əsaslı healthcheck-lər sonrakı mərhələdə əlavə edilməlidir.
